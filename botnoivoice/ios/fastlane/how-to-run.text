ถ้าคุณเซฟไฟล์ `Fastfile` และวางไฟล์ `.p8` ไว้ในโฟลเดอร์ `ios/fastlane/` เรียบร้อยแล้ว

ขั้นตอนต่อไปคือ **การสั่งรันโปรแกรม** ครับ

ให้ทำตาม 2 ขั้นตอนนี้ใน Terminal:

### 1\. เข้าไปที่โฟลเดอร์ ios

```bash
cd ios
```

### 2\. สั่งรัน Fastlane

```bash
fastlane beta
```

-----

### สิ่งที่จะเกิดขึ้น (นั่งดูจอได้เลย)

1.  มันจะฟ้องว่ากำลัง **Cleaning** โปรเจกต์
2.  มันจะเริ่ม **Build** (จะใช้เวลานานที่สุดตรงนี้ เหมือนเรากด Archive ใน Xcode)
3.  ถ้า Build เสร็จ มันจะ **Upload** ขึ้น App Store Connect ให้เองโดยใช้ API Key ที่เราตั้งไว้
4.  เมื่อเสร็จแล้ว มันจะขึ้นข้อความสีเขียวๆ ว่า **"Successfully distributed build to TestFlight"**

**หมายเหตุ:**
ถ้ามัน Error สีแดงขึ้นมาว่า `File not found` ตรงขั้นตอน Upload แสดงว่าชื่อไฟล์ `.ipa` ใน `Fastfile` ไม่ตรงกับที่เครื่องสร้างออกมา ให้คุณแก้บรรทัด `ipa: "..."` ใน `Fastfile` ให้ตรงกับชื่อไฟล์จริงครับ
