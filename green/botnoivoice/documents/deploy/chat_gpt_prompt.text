การแยกโค้ดออกเป็นส่วนๆ ที่คุณสังเกตเห็น เรียกว่า **"Refactoring"** โดยเฉพาะการแยกเป็น **"Reusable Widgets"** หรือ **"Modularization"** ใน Flutter เพื่อให้โค้ดสะอาด อ่านง่าย และดูแลรักษาได้ง่ายขึ้น

### คำศัพท์ (Keyword) ที่คุณสามารถใช้ในการสั่งงานได้:

1. **Refactor Widgets**  
   - ใช้เมื่อคุณต้องการแยกโค้ดเป็นส่วนย่อยๆ (Widget) ที่สามารถนำไปใช้ซ้ำได้

2. **Create Reusable Components**  
   - ใช้เพื่อสร้าง Widget ที่สามารถนำไปใช้ซ้ำในหลายที่

3. **Extract Widget**  
   - ใช้เมื่อคุณต้องการแยกบางส่วนของ UI ออกมาเป็น Widget ของตัวเอง

4. **Modularization**  
   - การแยกโค้ดหรือฟังก์ชันออกเป็นโมดูล (Modules) หรือส่วนประกอบย่อยๆ เพื่อลดความซับซ้อน

5. **UI Decomposition**  
   - การแบ่งส่วนของ UI ให้อยู่ใน Widget ย่อยหลายๆ ตัว

---

### ตัวอย่างการสั่งงาน (Prompt):
- **"Refactor Widgets"**:  
  *ช่วยแยกหน้าลงทะเบียนออกเป็นหลาย Widget ย่อยเพื่อให้โค้ดสะอาดและนำไปใช้ซ้ำได้*  
- **"Create Reusable Components"**:  
  *สร้าง Component สำหรับฟอร์ม TextField ที่ใช้บ่อย*  
- **"Extract Widget"**:  
  *แยกส่วนการแสดงปุ่ม Line และ Google Login ออกมาเป็น Widget ใหม่*

---

ด้วย Keyword เหล่านี้ คุณจะสามารถสั่งงานหรือขอให้ช่วยเขียนโค้ดในรูปแบบที่ต้องการได้ในอนาคต!
