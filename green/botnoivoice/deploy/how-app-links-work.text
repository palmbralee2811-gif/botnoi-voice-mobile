# How-App-Links-and-Universal-Links-Work

การตั้งค่า **App Links (Android)** และ **Universal Links (iOS)** จะไม่ส่งผลกระทบต่อการทำงานของระบบเดิมบนเว็บไซต์ (`https://voice.botnoi.ai`) ของคุณ ถ้าทำอย่างถูกต้อง เนื่องจากระบบจะทำงานแยกกันระหว่างเว็บและแอปพลิเคชัน โดยจะมีผลเฉพาะกับการเปิดลิงก์ในอุปกรณ์ที่มีแอปของคุณติดตั้งไว้เท่านั้น

### การทำงานของระบบ App Links และ Universal Links

- เมื่อคุณตั้งค่า App Links และ Universal Links แล้ว หากผู้ใช้คลิกลิงก์ `https://voice.botnoi.ai?mode=resetPassword&oobCode=XYZ123` บนอุปกรณ์ที่ติดตั้งแอปไว้ ระบบจะพยายามเปิดแอปของคุณและส่งข้อมูล `oobCode` ไปยังแอปของคุณโดยอัตโนมัติ
- หากผู้ใช้ไม่มีแอปติดตั้งไว้บนอุปกรณ์ หรือลิงก์ถูกเปิดในอุปกรณ์ที่ไม่รองรับ App Links/Universal Links (เช่น บนคอมพิวเตอร์หรือเบราว์เซอร์ในมือถือที่ไม่มีแอปของคุณ) ระบบจะเปิดลิงก์ไปที่หน้าเว็บไซต์ `https://voice.botnoi.ai` เหมือนเดิม

### สรุปการทำงาน
- **บนอุปกรณ์ที่ติดตั้งแอป**: ลิงก์จะเปิดแอปและนำข้อมูล `oobCode` ไปประมวลผล
- **บนอุปกรณ์ที่ไม่มีแอป**: ลิงก์จะยังคงเปิดเว็บไซต์ตามปกติ

### **จะมีผลกระทบอะไรบ้าง?**

#### 1. สำหรับผู้ใช้ที่มีแอปติดตั้งไว้:
   - ระบบจะเปิดแอปแทนการเปิดเว็บไซต์ เมื่อผู้ใช้คลิกลิงก์จากอีเมล
   - ข้อมูลจะถูกส่งไปยังแอปของคุณและประมวลผลต่อไปตามที่คุณตั้งค่าไว้

#### 2. สำหรับผู้ใช้ที่ไม่มีแอปติดตั้ง:
   - ไม่มีการเปลี่ยนแปลง ผู้ใช้จะถูกนำไปยังเว็บไซต์ `https://voice.botnoi.ai` เหมือนเดิม

### ข้อควรระวังในการตั้งค่า
- ตรวจสอบให้แน่ใจว่าไฟล์ `assetlinks.json` และ `apple-app-site-association` ถูกอัปโหลดไปยังตำแหน่งที่ถูกต้อง (`https://voice.botnoi.ai/.well-known/assetlinks.json` และ `https://voice.botnoi.ai/apple-app-site-association`) เพื่อให้ระบบสามารถทำงานได้ตามที่ตั้งค่า
- หากมีข้อผิดพลาดในการตั้งค่าไฟล์หรือการกำหนดค่า Universal Links/App Links แอปจะไม่เปิดเมื่อผู้ใช้คลิกลิงก์ และจะนำผู้ใช้ไปที่เว็บไซต์ตามปกติแทน

### ตัวอย่างการทำงานที่เป็นไปได้
- ผู้ใช้ขอรีเซ็ตรหัสผ่านและได้รับอีเมลพร้อมลิงก์
- เมื่อผู้ใช้คลิกลิงก์บนมือถือที่ติดตั้งแอปไว้ แอปจะเปิดขึ้นและประมวลผลการรีเซ็ตรหัสผ่าน
- หากผู้ใช้ไม่มีแอปติดตั้ง ลิงก์จะนำผู้ใช้ไปยังหน้าเว็บไซต์ของคุณตามปกติ

### สรุป
- การตั้งค่า App Links และ Universal Links จะเพิ่มประสิทธิภาพและประสบการณ์การใช้งานสำหรับผู้ที่มีแอป แต่จะไม่ส่งผลกระทบต่อระบบเว็บไซต์ปัจจุบันของคุณ
- ลิงก์จะยังคงนำผู้ใช้ไปยังหน้าเว็บตามปกติหากไม่ได้ติดตั้งแอป จึงไม่มีความเสี่ยงที่จะทำให้ระบบเดิมเสียหาย

ดังนั้นคุณสามารถดำเนินการตั้งค่าได้โดยไม่ต้องกังวลว่าระบบเว็บไซต์ปัจจุบันของคุณจะได้รับผลกระทบ.
